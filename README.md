# 📚 Telegram-бот: платный доступ к тестам

Бот на **aiogram 3.x** + **SQLite** (через `aiosqlite`) с разделением на пользователя и админа.
Поддерживает оплату доступа через ручную модерацию, прохождение тестов, статистику и автоматическую деактивацию истёкших подписок.

> ⚠️ В исходной задаче в `requirements.txt` была указана `python-telegram-bot==22.7`, но в описании — `aiogram 3.x`.
> Реализовано на **aiogram 3.x**, как указано в основном тексте задания. Список зависимостей обновлён.

## 🚀 Возможности

### Для пользователей
- Регистрация автоматически при `/start` (сохраняется `user_id`, `username`, имя, дата)
- Главное меню: **📚 Пройти тест**, **💳 Купить доступ**, **👤 Мой профиль**
- Без активного доступа — «Доступ не оплачен» + кнопка **✍️ Написать менеджеру**
- После «Написать менеджеру» появляется **🛒 Купить тест** → заявка уходит админу
- В профиле: ID, статус доступа, сколько осталось времени

### Для админа
- `/admin` — панель
- **📋 Заявки** — список + ответ пользователю / выдача доступа / отклонение
- **✅ Выдать доступ** — ввод ID → выбор срока (1 неделя / 1 месяц)
- **👥 Пользователи** — список с пагинацией, поиск по ID/username, карточка
- **📝 Тесты** — пошаговое добавление (FSM), удаление с подтверждением
- **📊 Статистика** — пользователи / активные подписки / заявки / тесты / прохождения

### Автоматика
- APScheduler каждый час чистит истёкшие записи в `access` и шлёт уведомления
- Все результаты прохождения тестов сохраняются в `results`
- Действия админа и ошибки пишутся в `logs/bot.log`

## ⚙️ Установка

```bash
# 1. Клонируйте или распакуйте проект и перейдите в его директорию
cd tgbot

# 2. Создайте виртуальное окружение
python3 -m venv venv
source venv/bin/activate     # Linux/Mac
# venv\Scripts\activate      # Windows

# 3. Установите зависимости
pip install -r requirements.txt

# 4. Скопируйте .env.example в .env и заполните
cp .env.example .env
# затем откройте .env и впишите BOT_TOKEN и ADMIN_ID

# 5. Запустите
python main.py
```

## 🔑 Переменные окружения (`.env`)

| Переменная   | Описание                                            | Пример                  |
|--------------|-----------------------------------------------------|-------------------------|
| `BOT_TOKEN`  | Токен бота от [@BotFather](https://t.me/BotFather)  | `123456:ABC-DEF...`     |
| `ADMIN_ID`   | Telegram ID админов (через запятую)                 | `111111111,222222222`   |

| `LOG_LEVEL`  | (опционально) уровень логов                         | `INFO`                  |

Узнать свой ID можно у [@userinfobot](https://t.me/userinfobot).

## 🗄 Схема БД

| Таблица     | Поля                                                                    |
|-------------|-------------------------------------------------------------------------|
| `users`     | `id`, `user_id`, `username`, `full_name`, `created_at`                  |
| `tests`     | `id`, `title`, `questions_json`, `created_at`                           |
| `access`    | `id`, `user_id`, `start_date`, `end_date`, `is_active`                  |
| `requests`  | `id`, `user_id`, `status` (`pending`/`granted`/`rejected`/`contacted`), `created_at` |
| `results`   | `id`, `user_id`, `test_id`, `score`, `total`, `completed_at`            |

Формат `questions_json`:

```json
[
  {"q": "Сколько будет 2+2?", "options": ["3", "4", "5"], "correct": 1}
]
```

(`correct` — индекс правильного варианта, 0-based)

## 📝 Как пользоваться

### Пользователь
1. `/start` → выбирает «💳 Купить доступ» → «✍️ Написать менеджеру» → «🛒 Купить тест»
2. Получает ответ админа с реквизитами, оплачивает
3. Админ выдаёт доступ — приходит уведомление
4. Открывает «📚 Пройти тест», проходит, видит результат

### Админ
1. `/admin` → панель
2. **📋 Заявки** → выбрать заявку → **💬 Ответить пользователю** (написать цену/реквизиты)
3. После оплаты: в той же заявке → **✅ Выдать доступ** → «1 неделя» или «1 месяц»
4. **📝 Тесты** → **➕ Добавить тест** → пошагово: название → вопрос → варианты → правильный → следующий вопрос → `/done`
5. В любой момент `/cancel` — выйти из FSM-диалога
